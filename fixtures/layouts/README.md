# Saved graph layouts

Each JSON file maps stable node ids to generated `{ "x": number, "y": number }` positions only.
The generator is `frontend/tools/layout.ts`; it uses sorted ids and no force simulation or random
seed. Commands below run from the repository root with the frozen dependencies installed.

## demo-repo.json

Our own code in `demo-repo/`. Regenerate from the committed graph snapshot and update the
hand-written replay's positions:

```sh
make layout
node frontend/tools/check-preset.ts fixtures/graph/demo-repo.json fixtures/layouts/demo-repo.json
```

## boltons-d31d821.json

Node ids derived from [Boltons](https://github.com/mahmoud/boltons)' qualified names at pinned
commit [d31d821d56c8f7756af9c30a864077f2e5855321](https://github.com/mahmoud/boltons/tree/d31d821d56c8f7756af9c30a864077f2e5855321),
licensed [BSD-3-Clause](https://github.com/mahmoud/boltons/blob/d31d821d56c8f7756af9c30a864077f2e5855321/LICENSE).
Positions are generated by Oversight. No Boltons source text, docstrings or code is stored in this
preset. The fetched checkout and bare snapshot stay under the gitignored `.runtime/` directory.

```sh
# The only network step; validates the pin when the checkout already exists.
make workspace-fetch-boltons
# Everything below is offline.
make workspace-graph-boltons
node frontend/tools/layout.ts --input .runtime/graphs/boltons-d31d821.snapshot.json --output fixtures/layouts/boltons-d31d821.json
node frontend/tools/check-preset.ts .runtime/graphs/boltons-d31d821.snapshot.json fixtures/layouts/boltons-d31d821.json
```

The check regenerates twice in separate Node processes, compares both outputs byte for byte with
the committed preset, and checks complete node coverage and finite coordinates with no extra fields.
It needs the explicitly exported snapshot; normal checks never fetch Boltons.

Set `OVERSIGHT_WORKSPACE_SOURCE=boltons-d31d821` and
`OVERSIGHT_LAYOUT=fixtures/layouts/boltons-d31d821.json` before starting the live server to use this
preset. Re-export and regenerate when the source pin or graph parser changes.

With that server and its Vite frontend already running, verify the actual layout branch and capture
the initial and Modules views at 1920×1080:

```sh
node frontend/shots/boltons-preset.ts http://127.0.0.1:5710/ .shots/boltons-preset
```

This explicit check compares `GET /graph` with the entire preset and records the layout branch
executed in the browser. It also renders the same snapshot without positions through a hand-written
fake event stream for the fallback comparison. `audit.json` reports intersections between module
cards and hidden call routes in model space, across the whole graph rather than just the viewport.
Captures and audit output remain uncommitted under `.shots/`.
