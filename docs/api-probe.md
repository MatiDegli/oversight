### Verdict

Native tools. Front 12 sends `tools` and reads `tool_calls` in Chat Completions, then answers each call with one `tool` message. Parallel calls: yes, 2 calls in one turn. The reply can carry text next to a tool call, so `content` is not the end. Reasoning: with no parameter, on by default (258 reasoning tokens with no parameter); `reasoning_effort` low was accepted; none was rejected, HTTP 400. The API lists these values as supported: minimal, low, medium, high, xhigh, max. One sample each, on a trivial prompt: low gave 212 reasoning tokens and the default 258, so what each setting costs is still unmeasured.

### Documented, not probed

- `tool_choice` accepts only `auto`; `none`, `required` and a named function return HTTP 400.
- `stop` is not supported on reasoning models and returns HTTP 400; `top_p: 0` returns 400.
- A function name must match `^[a-zA-Z0-9_.-]+$` with at most one dot.
- Reasoning tokens count toward `max_completion_tokens` and are billed as output.
- `reasoning_content` is redacted to empty for external keys, so there is nothing to send back.
- Rate limit for muse-spark-1.3: 3,000 requests and 4,000,000 tokens per minute, per team.
- A 429 should be retried with exponential backoff and jitter, honoring `Retry-After`.
